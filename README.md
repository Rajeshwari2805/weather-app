# 🌤️ Real-Time Weather Web App

A sleek, responsive, and minimalist weather web app that fetches live global weather data without requiring restrictive API keys. Designed with a modern glassmorphism UI, the application dynamically shifts its visual state based on real-time environmental conditions.

🔗 **[Live Demo URL](https://your-username.github.io/your-repo-name/)**

---

## ✨ Features

* **Real-Time Data Fetching:** Instantly retrieves accurate weather metrics for any global city.
* **Dual API Chaining:** Seamlessly passes user-searched city queries to a geocoding engine to retrieve coordinates, which then fuel the primary weather telemetry payload.
* **Dynamic UI/UX:** The background UI fluidly transitions using CSS gradients and animations based on the current weather condition of the searched location.
* **Live Time Tracking:** Features an integrated real-time clock updating every second to match the user's interface flow.
* **Fully Responsive:** Optimised for flawless viewing across mobile devices, tablets, and desktop displays.

---

## 🛠️ Tech Stack & Key Concepts

* **Structure:** HTML5
* **Styling:** CSS3 (Custom gradients, keyframe animations, and modern `backdrop-filter` for glassmorphism)
* **Logic:** Vanilla JavaScript (ES6+, asynchronous operations using native `fetch` and `async/await`)
* **Weather Data Suite:** Open-Meteo API (Open-source, free tier, no API key required)
* **Geocoding Engine:** Open-Meteo Geocoding API
* **Typography:** Google Fonts (Outfit)
* **State Management:** Time synchronization built using native `setInterval`
